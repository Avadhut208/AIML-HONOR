## Run on Windows

Open Command Prompt in the folder containing this README. Use Python 3.9 or newer. Each command runs a separate assignment.

```bat
py assignment-1\main.py
py assignment-2\main.py
py assignment-3\main.py
py -m pip install -r assignment-4\requirements.txt
py assignment-4\main.py
```

The employee programs create their own data files alongside their scripts. All example records are fictional. Use one instance of the CSV program at a time. Each assignment folder contains its own lab notes and demonstration steps. Original course references are in course-materials.
